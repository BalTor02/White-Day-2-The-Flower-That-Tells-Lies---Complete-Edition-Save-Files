## Overview

This repository provides targeted save files for **White Day 2: The Flower That Tells Lies - Complete Edition** to help players unlock endings and Steam achievements without requiring a full replay:

* **Story 1 (Returning to School):** Save files positioned to trigger all 5 main story endings (Deception, Distrust, Wrong Choice, Crucial Mistake, Confession) and achievements.
* **Story 2 (Who Killed Her):** Save files configured to unlock all 5 main story endings (Dissonance, Karma, Blackout, Kkotnim sweetheart, Endless whispers) and achievements.
* **Story 3 (Her Story):** Save files ready to trigger all 4 main story endings (Sacrifice, All for Nothing, Revenge, Revenge Incarnate) and achievements.
* **Gallery Collections:** Standalone collection files (`EndingCollection.sav` for 14/14 endings and `GhostCollection.sav` for 18/18 ghost photos) to unlock Main Menu extras without overwriting personal campaign save data.

---

## Installation Guide

1. Press **Windows + R** to open the Run dialog.
2. Type `%LOCALAPPDATA%\WD\Saved` and press **Enter**.
3. Back up your existing **SaveGames** directory to a safe location.
4. Extract the [Downloaded Save File (.zip)](https://github.com/BalTor02/White-Day-2-The-Flower-That-Tells-Lies---Complete-Edition-Save-Files/releases/download/Version4.0/White_Day_2_Save_Files.zip).
5. Copy and paste the provided **SaveGames** folder into `%LOCALAPPDATA%\WD\Saved`, overwriting existing files when prompted.
6. Launch the game and select the corresponding save slot.
